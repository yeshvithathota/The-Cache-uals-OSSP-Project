# Linux Alarm Clock System

## 1. Project Overview

The Linux Alarm Clock System is a C-based Linux system programming project.

The system allows users to create alarm requests using a delay in seconds. Each alarm is managed by a separate child process. Linux timers and signals are used to generate the alarm event.

The waiting child process is suspended using `pause()` instead of continuously consuming CPU.

The system also supports cancellation and multiple active alarms.

---

## 2. Requirements Implemented

The project implements:

- Accepting alarm delay from the user
- Creating a process for each alarm
- Using `alarm()` as the timer
- Using `SIGALRM` for alarm notification
- Suspending the process using `pause()`
- Handling signals using signal handlers
- Displaying alarm notification
- Cancelling active alarms
- Handling multiple alarm requests
- Parent-child synchronization using `waitpid()`

---

## 3. Operating System Concepts

### Process Creation
`fork()` creates a separate child process for every alarm.

### Signals
`SIGALRM` is generated when the timer expires.

`SIGTERM` is used to cancel an active alarm.

### Process Suspension
`pause()` suspends the child process until a signal is received.

### Process Synchronization
`waitpid()` allows the parent to wait for child processes.

### System Call Analysis
`strace` is used to observe system calls generated by the program.
